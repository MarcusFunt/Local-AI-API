# Chatterbox's watermarker dependency (resemble-perth) imports the legacy
# pkg_resources module, which setuptools removed in 81.0. On Python 3.12 slim
# images the default setuptools is newer, so perth's import silently fails and
# Chatterbox TTS crashes with "'NoneType' object is not callable". Pin
# setuptools below 81 so pkg_resources stays available.
setuptools<81
